# GFX References 보관함 (크롬 익스텐션)

핀터레스트 같은 사이트에서 마음에 드는 사진을 **보관함**에 담아 두었다가, 나중에 골라서 GFX References 에 올립니다.

- **핀터레스트**: 사진 위에 마우스를 올리면 왼쪽 위에 **「GFX에 담기」** 버튼이 나옵니다.
  작은 미리보기가 아니라 **원본 크기**로 담아요.
- **다른 사이트**: 사진을 오른쪽 클릭 → **「GFX 보관함에 담기」**
- 담은 사진은 이 컴퓨터의 크롬 안에만 저장돼요. **올리기 전까지 서버에는 아무것도 가지 않습니다.**
- 툴바의 익스텐션 아이콘을 누르면 보관함이 열려요. 아이콘의 숫자는 아직 올리지 않은 사진 수입니다.
- 보관함에서 사진을 고르고 분류 · 태그 · 제작자를 정한 뒤 **올리기**.
  출처(핀 주소)도 함께 저장되어 사이트 상세 화면의 **Source** 와 디스코드 아카이브에 보여요.

## 설치 (웹 스토어 없이)

1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 이 `chrome-extension` 폴더 선택
4. 퍼즐 모양 아이콘에서 **GFX References 보관함** 을 고정하면 편해요.
5. 이미 열려 있던 핀터레스트 탭은 **새로고침**해야 버튼이 나와요.

코드를 고친 뒤에는 `chrome://extensions` 에서 이 익스텐션의 **새로고침(⟳)** 을 누르세요.

## 처음 올릴 때: 디스코드 연동

1. 보관함 오른쪽 위 **🔗 디스코드 연동**
2. 표시된 명령어(`/연동 코드:XXXX-XXXX`)를 디스코드에 입력 → 자동으로 연동돼요.
3. 포토샵 플러그인과 같은 방식이고, 180일 동안 유지돼요. GFX References 디스코드 서버 멤버만 올릴 수 있어요.

## 알아 둘 점

- 1분에 10장까지 올릴 수 있어서, 많이 고르면 중간에 잠깐씩 기다렸다가 계속해요.
- 비슷한 사진이 이미 있으면 그 번호를 알려 주고, **그래도 올리기**를 누를 수 있어요.
- 10MB 가 넘는 사진은 서버가 화질을 최대한 지키며 줄여서 보관해요.
- 핀터레스트 외의 사이트는 사진을 바로 못 받을 때가 있어요. 그러면 주소만 담아 두고,
  올릴 때 크롬이 **그 사이트 접근 허용**을 한 번 물어봐요.
- 사진은 직접 누른 것만 담아요. 보드 전체를 자동으로 가져오는 기능은 없어요 (핀터레스트 규칙).
- 핀터레스트가 화면 구조를 바꿔 버튼이 안 보이면, 오른쪽 클릭으로 담으면 됩니다.

## 폴더 구성

```
chrome-extension/
  manifest.json          권한 · 핀터레스트 주소 · 아이콘
  background.js          오른쪽 클릭 메뉴, 담기 요청 처리, 아이콘 숫자
  content/pinterest.js   핀터레스트의 「GFX에 담기」 버튼
  library.html/.css/.js  보관함 화면 (보기 · 고르기 · 올리기 · 연동)
  lib/box.js             보관함 저장소 (IndexedDB) 와 핀터레스트 원본 주소 찾기
  lib/core.js            서버 통신 — photoshop-plugin/gfx-ref/core.js 와 같은 파일 (복사본)
  icons/
```

`lib/core.js` 는 포토샵 플러그인의 것을 그대로 복사한 파일이에요. 한쪽을 고치면 다른 쪽에도 복사해 주세요
(서버 테스트가 두 파일이 같은지 확인합니다).

## 웹 스토어에 올리려면

크롬 웹 스토어 개발자 등록(1회 5달러) 후 이 폴더를 zip 으로 묶어 올리면 됩니다. 심사에 며칠 걸릴 수 있어요.
